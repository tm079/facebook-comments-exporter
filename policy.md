# Privacy Policy

**Last updated: 2026**

## Information We Process

Export Comments for Facebook™ processes **website content** that is visible on Facebook pages when the user explicitly activates the extension. This may include:

- Comment text  
- Commenter name  
- Timestamp  
- Like count  

All data is processed **locally on the user’s device** for the sole purpose of exporting comments. We do **not** collect, store, or transmit Facebook content to external servers.

---

## Analytics & Extension Usage Data

We may collect **basic, anonymized usage data** to understand how the extension is used, such as:

- Which extension features are used  
- Extension popup views  
- Basic session events  

This data is anonymized and cannot be used to identify individual users. It is used solely to improve extension functionality and user experience.

---

## Local Storage

We use the **Chrome Storage API** to store basic user preferences (such as export format or selected options).  
This information is stored **locally in your browser** and is accessible only by the extension.

---

## What We Do NOT Collect

- Facebook account credentials  
- Passwords or authentication information  
- Personal messages  
- Financial or payment information  
- Location data or browsing history  

We do not have access to your Facebook account beyond reading visible content required to perform the export action.

---

## Permissions

The extension requests permission to access **facebook.com** only so it can read comment content on pages that the user owns, manage, or have permission to access.  
The extension does not operate outside of Facebook domains.

---

## Data Sharing

We do **not** sell, share, or transfer user data to third parties.  
All processing is limited strictly to the extension’s single purpose: exporting Facebook comments.

---

## Security

The extension is designed to be simple and secure.  
Aside from optional anonymized analytics, all core functionality runs locally in the browser.  
No Facebook content is transmitted to external servers.
